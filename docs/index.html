Windows link routing utility

Browser Wrangler

Browser Wrangler registers itself as a browser on Windows and routes links to the right browser and profile based on your rules.

Download latest release View source on GitHub

Install

Install with winget:

winget install DamianH.BrowserWrangler

Or download installers and portable ZIPs from the latest release.

Features

  • Rule-based routing for URL, domain, and path matching.
  • Browser and profile discovery including Chromium and Firefox profiles.
  • Picker popup with keyboard shortcuts when multiple matches exist.
  • URL processing pipeline for safe-link unwrapping and substitutions.
  • Fast startup and no always-on background process.
